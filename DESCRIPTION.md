# Healthie Scorer — description

**GitHub about (short)**  
Working prototype: scan a pack, get an independent 0–100 score in plain English. Food, beauty, pet. Not a store app. Not the Healthie EHR.

**Store / press (one breath)**  
A reading aid for the shelf. Barcode or photo. A number you can say out loud, teaspoons of sugar, extras worth watching, a better neighbour in the same aisle. No brand pays for a better number. Not a diagnosis. Not the EMR named Healthie.

**What it is**  
A consumer scoring prototype from Digital Currensy Inc. Live demo: https://healthie-hazel.vercel.app

**What it is not**  
Not a medical device. Not Yuka. Not Open Food Facts on a phone. Not gethealthie.com (ONC-certified EHR). Not App Store ready.

**Status (Sept 2026)**  
Walkable demo. Presenter path: Home → Coca-Cola 35 → Evian 95 → why. Camera works on a top-level PWA / HTTPS tab, not inside an embedded preview. Catalog is a photographed demo shelf plus live OFF / USDA FDC / OpenFDA lookups — not a national inventory.

**Owner**  
Digital Currensy Inc. Private repository. Source is not a contribution playground.
