# Digestible messaging

Healthie speaks like a person next to you at the shelf. Short sentences. No lab as the headline. A number you can repeat.

The on-product voice lives in `src/lib/copy.ts`. This page is the source for marketing, store listings, and support.

## The line

> Scan a pack. Know immediately.

Support line, always nearby:

> Independent scores. No brand pays for a better number.

Legal-adjacent, never hidden:

> Healthie is a reading aid, not a diagnosis. If you have an allergy, always check the pack.

## How a score is said

| Band | Word on the ring | Sentence (food) |
| --- | --- | --- |
| 80–100 | Excellent | A keep. Short list, honest nutrition. |
| 60–79 | Good | Fine sometimes. Not the best in the aisle. |
| 40–59 | Poor | A treat at best. Look one shelf over for a better everyday pick. |
| 0–39 | Avoid | Hard pass for a regular shop. Better swaps are close by. |

Beauty uses “calm formula / we’d leave on the shelf.” Pet uses “solid bowl / skip this bag.” Same bands. Different nouns.

## Words we use

- Pack, aisle, bowl, tin, bottle — not SKU, SKU family, or “SKU-1”
- Teaspoons of sugar — not only g/100 ml
- Ultra-processed — headline; NOVA 4 can sit in the small print
- Worth watching / high concern — not “toxic” as a default
- Body & beauty — not “cosmetics vertical”
- Independent — not “unbiased AI”

## Words we refuse

| Don’t say | Say instead |
| --- | --- |
| Superfood / detox / cleanse | Short list, honest recipe |
| Clinically proven (unless the pack does, and we quote it) | What’s in it |
| Toxic, poison, banned | High concern, we’d skip |
| Our algorithm | How we read the pack (method page) |
| Doctors hate this | — (never) |
| Personalized medicine | Notes on this phone / this account |
| E250 as the only name | Sodium nitrite — and then the code if someone wants it |

## Scan, said out loud

- **Scan barcode** — opens the lens. Hold the pack in the window.
- **Take photo** — snaps the front if there is no barcode, or the lens is blocked.
- **Camera roll** — only if you already have a shot.
- **Type the numbers** — the digits under the barcode.
- **Try a scored pack** — Coca-Cola, Nutella, and the rest, when this window has no camera.

Never tell someone the live camera is on when the window cannot hold a lens. Never call a file picker “the camera” on a computer.

## Three-line pitch

1. You scan the pack in your hand.
2. You get a number and a reason you can say.
3. Nobody paid for that number.

## Support replies (keep these)

**“Is this medical advice?”**  
No. It’s a reading aid. If you have an allergy or a condition, check the pack and your clinician.

**“Did the brand pay?”**  
No. No brand pays for a better score.

**“Why is Coke 35?”**  
Sugar and ultra-processing. Poor for a daily drink. The page says that in sentences, not a dunk.

**“You don’t have my barcode.”**  
Photograph the front. We’ll read the name. If we still miss, we say so — we don’t invent a score.

## Tone checks

- Would you say it to a tired parent in a Tesco aisle? If not, rewrite.
- Can they repeat the score word without looking? Excellent / Good / Poor / Avoid.
- Did we sneak a method name (Nutri-Score, NOVA, ZXing) into the first screen? Move it down.
